대상자 관리 ↔ Google 시트 연동 설정 가이드

브라우저 저장(localStorage)을 넘어, 여러 명이 한 시트에 저장·공유하도록 백엔드를 붙입니다 · 약 5분

⚠️ 먼저 확인 — 이 실시간 연동은 배포된 페이지(예: butprompter.com/malli-dashboard.html)에서만 동작합니다. claude.ai 미리보기(Artifact)는 외부 연결이 차단되어 시트 호출이 실패합니다. 시트 연동을 쓰려면 대시보드를 GitHub Pages(자체 도메인)에 올린 뒤 그 페이지에서 사용하세요.

A. 왜 이걸 하나요?

대상자 관리 탭의 대응상태·담당자·메모는 원래 내 브라우저(localStorage)에만 저장됩니다. 즉 다른 사람·다른 PC와 공유되지 않습니다. Google 시트를 백엔드처럼 연결하면 여러 명이 같은 시트에 저장하고 최신 상태를 함께 볼 수 있습니다. 별도 서버 없이 무료로 됩니다.

B. 설정 순서

  1. Google 시트를 새로 하나 만듭니다(내용은 비어 있어도 됩니다).
  2. 상단 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 기본 코드(function myFunction(){})를 모두 지우고, 아래 C. 코드를 통째로 붙여넣은 뒤 저장(💾)합니다.
  4. 오른쪽 위 배포 → 새 배포를 누릅니다.
  5. 톱니바퀴(유형 선택) → 웹 앱을 고릅니다.
  6. 설정 — 실행: 나(본인), 액세스 권한: 모든 사용자 로 두고 배포.
  7. 권한 승인 창이 뜨면 본인 계정으로 허용합니다(“안전하지 않음” 경고가 보이면 고급 → 이동).
  8. 발급된 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.
  9. 대시보드 대상자 관리 탭 → ☁ 시트 칸에 URL을 붙여넣습니다(자동 기억됨).
  10. (최초 1회 시딩) 대시보드에서 👥 담당자 자동배분 → 💾 저장. 배정된 명단(담당자·세그먼트)이 시트 대상자관리 탭에 한글 헤더로 채워집니다.

B-2. 운영 방식 (권장: 시트 입력 · 어드민 모니터링)

10명이 동시에 쓰기 때문에, 입력은 Google 시트에서, 관리자는 어드민에서 모니터링하는 방식을 권장합니다.

  1. 직원 10명: 시트 대상자관리 탭에서 담당자 열로 필터(데이터 → 필터 보기)해 본인 대상자만 봅니다. 통화하며 통화결과 · 핵심전환 · 1주후재접속 · 메모 칸을 채웁니다. 세그먼트별 대본은 대시보드 "이탈·리텐션/대상자 관리" 또는 보고 대본을 참고.
  2. 관리자: 어드민 대상자 관리 탭에서 ↓ 불러오기를 누르거나 🔄 자동새로고침을 켜면(30초 주기) 시트 최신 입력이 반영되어 세그먼트별/담당자별 진도, A/B 재접속 비교가 자동 계산됩니다.
⚠️ 어드민의 자동새로고침은 미저장 편집이 있으면 건너뜁니다(직원 입력을 덮어쓰지 않도록). 관리자가 어드민에서 직접 수정·저장하면 시트를 전체 교체하므로, 동시 편집 중에는 관리자는 보기 전용으로 쓰는 것을 권장합니다.

C. 붙여넣을 코드 (Code.gs)

저장소 파일 malli-sheets-appsscript.gs와 동일합니다. 시트는 한글 헤더(사람이 읽기 쉬움)로 두고, 이 스크립트가 어드민 키와 자동 매핑합니다.

var SHEET_NAME = '대상자관리';
var FIELDS = [
  { key:'id', label:'id' }, { key:'name', label:'이름' },
  { key:'risk', label:'위험도' }, { key:'dsl', label:'미접속일' },
  { key:'seg', label:'세그먼트' }, { key:'owner', label:'담당자' },
  { key:'status', label:'진행상태' }, { key:'call_result', label:'통화결과' },
  { key:'conversion', label:'핵심전환' }, { key:'reengaged', label:'1주후재접속' },
  { key:'memo', label:'메모' }, { key:'updated_at', label:'최종수정' }
];
var LABELS = FIELDS.map(function(f){ return f.label; });

function sheet_(){
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(SHEET_NAME);
  if(!sh){ sh = ss.insertSheet(SHEET_NAME); sh.appendRow(LABELS); }
  return sh;
}
function json_(obj){
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
function doGet(e){
  var sh = sheet_();
  var values = sh.getDataRange().getValues();
  var head = values.shift() || LABELS;
  var colOf = {}; head.forEach(function(h,i){ colOf[String(h).trim()] = i; });
  var rows = values
    .filter(function(r){ return String(r[colOf['id']]||'').trim() !== ''; })
    .map(function(r){ var o={};
      FIELDS.forEach(function(f){ var i=colOf[f.label]; o[f.key]=(i!=null&&r[i]!=null)?r[i]:''; });
      return o; });
  return json_({ ok:true, rows:rows });
}
function doPost(e){
  var body = {};
  try{ body = JSON.parse(e.postData.contents || '{}'); }catch(err){}
  var rows = body.rows || [];
  var sh = sheet_();
  sh.clearContents();
  sh.appendRow(LABELS);
  if(rows.length){
    var out = rows.map(function(r){
      return FIELDS.map(function(f){ return r[f.key]!=null ? r[f.key] : ''; });
    });
    sh.getRange(2,1,out.length,LABELS.length).setValues(out);
  }
  return json_({ ok:true, count:rows.length, saved_at:new Date().toISOString() });
}

D. 개인정보 주의

시트에는 이름(마스킹)·위험도·대응상태 등 개인정보 성격의 명단이 담깁니다. “모든 사용자” 액세스는 URL을 아는 사람은 접근 가능하다는 뜻이니, URL은 내부에만 공유하고 시트 공유 범위도 팀 내부로 제한하세요. Google Workspace라면 시트 자체를 조직 내부 공유로 두는 것을 권장합니다.
문제가 생기면: URL이 /exec로 끝나는지, 배포 액세스가 “모든 사용자”인지, 코드 수정 후 새 배포(또는 배포 관리 → 편집 → 버전 새로 만들기)를 했는지 확인하세요. 미리보기(Artifact)에서는 항상 실패하는 것이 정상입니다.
