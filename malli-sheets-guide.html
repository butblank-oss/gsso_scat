맬리 브레인 · TM 운영

담당자 10개 시트 자동생성 + 통합 현황 워크북

하나의 Google 시트 안에서 배분·통화기록·현황·진도까지 전부 · Apps Script 1개 · 약 5분

A. 질문 3가지에 대한 답

1. 담당자 자동배분은 어떻게?
시트에 아래 스크립트를 붙이면 상단에 [맬리 TM] 메뉴가 생깁니다. [① 담당자 배분 + 10개 시트 생성]을 한 번 누르면 대상 374명(유지 제외)이 매트릭스대로 10명에게 배분됩니다.
2. 입력_통화기록·통계·진도를 시트에 다 담을 수 있나?
네. 전부 시트 안에 탭으로 자동 생성됩니다. 어드민에 따로 설정할 것 없이 시트가 원본입니다. 어드민은 이 시트를 원격에서 들여다보는 창(선택)일 뿐입니다.
3. 담당자별 10개 시트로 나누고 통합 현황?
정확히 그렇게 만듭니다. 담당자_이름 탭 10개 + 이를 합산하는 [현황판] 탭이 생성됩니다.

B. 생성되는 탭 구성

📋 원본_명단 (입력: 대상자 CSV 붙여넣기) 👤 담당자_김다희 … 담당자_이용혁 (×10) 📊 현황판 (자동 집계) 📝 스크립트 (세그먼트별 대본)

담당자 탭 각 열: 순번 · id · 이름 · 세그먼트 · 미접속일 · 통화일시 · 통화결과 · 핵심전환 · 1주후재접속 · 진행상태 · 메모(드롭다운 제공). 담당자는 본인 탭만 채우면 됩니다.
현황판: 세그먼트별(배정·시도·연결·전환·연결률) + A/B 재접속 비교 + 담당자별(배정·시도·연결·진행률). 10개 탭을 합산합니다.

C. 설치 (5분, 1회)

  1. 대상 시트에 원본_명단 탭을 만들고, 어드민 ⬇ CSV 내보내기 결과(또는 지금 컨테이너 시트의 명단)를 붙여넣습니다. 최소 id · 이름 · 위험도 · 미접속일 열이 있으면 됩니다.
  2. 상단 확장 프로그램 → Apps Script를 엽니다.
  3. 저장소 파일 malli-sheets-appsscript.gs 전체를 복사해 붙여넣고 저장(💾). (채팅으로도 파일을 드렸습니다.)
  4. 시트로 돌아와 새로고침 → 상단에 맬리 TM 메뉴가 생깁니다.
  5. 맬리 TM → ① 담당자 배분 + 10개 시트 생성 클릭. (권한 승인 창이 뜨면 본인 계정으로 허용 → “안전하지 않음”이면 고급 → 이동.)
  6. 끝. 담당자 탭 10개 + 현황판 + 스크립트가 생성됩니다.

D. 운영

  1. 직원 10명: 본인 담당자_이름 탭에서 통화하며 통화결과·핵심전환·1주후재접속·진행상태·메모를 드롭다운으로 입력. (서로 다른 탭이라 충돌·덮어쓰기 없음.)
  2. 관리자: 통화가 쌓이면 맬리 TM → ② 현황판 새로고침을 눌러 최신 집계를 봅니다. (원하면 시간 기반 트리거로 자동화 가능.)
  3. 1주후_재접속은 통화 1주 뒤 앱 로그를 확인한 PM이 채웁니다(통화 당일엔 비워둠).
단기이탈 A(리워드)/B(사용지원)는 자동으로 절반씩(82/81) 나뉘어 배정됩니다. A/B 효과 비교(1주후 재접속률)는 현황판에서 자동 계산되니, 배정된 조 그대로 진행해 주세요.

E. (선택) 어드민에서 원격 모니터링

시트만으로 충분하지만, 어드민 대시보드에서 원격으로 진도를 보고 싶다면: Apps Script 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자) → URL을 어드민 대상자 관리 탭 ☁ 시트 칸에 붙여넣고 ↓ 불러오기 또는 🔄 자동새로고침. 어드민은 보기 전용으로 쓰세요(어드민에서 저장하면 집계가 꼬일 수 있어, 입력은 시트에서만).

⚠️ 개인정보: 시트에는 이름(마스킹)·위험도 등 명단이 담깁니다. 시트 공유는 직원 10명 + 관리자 내부로만 제한하세요. 웹 앱 배포(“모든 사용자”)를 쓸 경우 URL을 외부에 노출하지 마세요.
문제 시: [맬리 TM] 메뉴가 안 보이면 시트를 새로고침 · ① 실행 오류가 나면 원본_명단 탭에 id/위험도 열이 있는지 확인 · 현황판 수치가 안 맞으면 [② 현황판 새로고침] 재실행.
