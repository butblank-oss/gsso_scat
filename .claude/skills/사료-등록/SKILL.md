# 사료 등록

정책 원문은 `docs/DATA-POLICY.md`. 충돌하면 정책이 우선한다.

## 네가 하는 일과 하지 않는 일

| 한다 | 하지 않는다 |
|---|---|
| 출처를 찾고 URL을 남긴다 | **점수를 매긴다** |
| 사실(facts)을 원문 인용과 함께 뽑는다 | 성분을 추측해 채운다 |
| 값을 스테이징에 올린다 | data.js 를 직접 고친다 |

**점수는 네가 매기지 않는다.** `scripts/lib/rubric.mjs` 가 계산한다.
너는 사실만 뽑고, `ratings` 는 그 루브릭을 그대로 적용해 채운다.
직접 판단한 점수를 넣으면 게이트 1에서 탈락한다.

## 절대 규칙

1. **출처 없으면 등록하지 않는다.** 기억이나 추론으로 값을 채우지 않는다.
2. 확인이 안 되는 사료는 **그냥 건너뛴다.** 억지로 채우지 말 것.
3. 모든 사실에 **원문 인용문**을 남긴다. URL만 있고 인용이 없으면 탈락한다.
4. 블로그·카페·리뷰·검색 요약문은 근거로 쓸 수 없다.

## 출처

| role | 대상 | 쓸 수 있는 곳 |
|---|---|---|
| `official` | 제조사 공식 사이트 | 성분·영양 |
| `importer` | 국내 공식 수입사 | 성분·영양 |
| `retail` | 쿠팡 등 판매처 상세 | 가격, 성분은 보조만 |

성분 근거는 **`official`/`importer` 1곳** 또는 **`retail` 2곳이 일치**해야 한다.
가격 근거는 `retail` 1곳이 반드시 있어야 한다.

## 뽑아야 할 사실 (facts)

| 키 | 내용 | 구하는 법 |
|---|---|---|
| `protein` | 조단백 (%) | 보장성분표 |
| `dmCarb` | 건물기준 탄수 (%) | `computeDmCarb()` 로 계산 (아래) |
| `firstIngrCat` | 1번 원료 분류 | `meat` / `fish` / `grain` / `veg` / `other` |
| `cautionN` | 주의 성분 개수 | 아래 목록 참고 |
| `dangerN` | 위험 성분 개수 | 아래 목록 참고 |

### 건물기준 탄수 계산

```
탄수(습식) = 100 - (조단백 + 조지방 + 조섬유 + 수분)
dmCarb    = 탄수(습식) / (100 - 수분) × 100
```

**조회분은 빼지 않는다.** 기존 41종이 이 방식으로 계산돼 있고, 조회분을 반영하면
dmCarb 가 약 9%p 낮아져 루브릭 경계가 전부 어긋난다.
직접 계산하지 말고 `scripts/lib/rubric.mjs` 의 `computeDmCarb()` 를 쓴다.

### 주의 성분 (cautionN)

천연 향미제, 효모 추출물, 옥수수·밀·대두 등 곡물 충전재, 육분(출처 불명),
동물성 유지(출처 불명), 정제 소금, 카라기난, 셀룰로스

### 위험 성분 (dangerN)

BHA, BHT, 에톡시퀸, 프로필갈레이트, 인공 착색료(적색 40호 등),
아질산나트륨, 프로필렌글리콜

## 채점 (직접 매기지 말고 그대로 적용)

```
원료     조단백 32%↑=5 · 25%↑=4 · 16%↑=3 · 미만=2
         단, 1번 원료가 곡물이면 최대 3점
탄수화물  건물기준 25%↓=5 · 35%↓=4 · 44%↓=3 · 56%↓=2 · 초과=1
첨가물    주의 0개=5 · 1~2개=4 · 3~4개=3 · 5개↑=2
         단, 위험 성분이 있으면 최대 3점
가성비    kg당 1만원↓=5 · 1.6만↓=4 · 3.2만↓=3 · 4.5만↓=2 · 초과=1
```

`score` 는 `2 × (0.45·원료 + 0.28·첨가물 + 0.20·탄수 + 0.07·가성비)`, 소수점 1자리.

## 출력

`data/staging/YYYY-MM-DD-collect.json` 에 쓴다. 형식은 `data/staging/_example.json` 참고.
`status` 는 항상 `draft` 로 둔다. 발행은 사람이 한다.

## 마치기 전에

```bash
node scripts/gate1-validate.mjs
```

탈락한 항목은 **고치려 하지 말고 배치에서 빼라.** 확인이 안 된 사료는 등록하지 않는 것이 맞다.
